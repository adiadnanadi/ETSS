1. Otvori Google Drive API i klikni Enable.
  • 2. Otvori Credentials → Create Credentials → OAuth client ID.
  • 3. Application type: Web application. Under Authorized redirect URIs dodaj: PLACEHOLDER_REDIRECT
  • 4. Copy Client ID i Client Secret u env varijable na Renderu: GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET.

    • Nakon toga klikni "Poveži Google Drive" ispod.
